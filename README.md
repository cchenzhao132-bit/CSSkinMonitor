# CSSkinMonitor
CSSkinMonitor 是一个完全用 vibe coding 方式打造的开源项目：作者不写一行代码，只负责提需求、拍板和验收，从 Steam 市场爬虫、数据管道到桌面客户端，全部通过与 AI 对话迭代完成。  它首先是一个趁手的工具：内置爬虫抓取 Steam 社区市场真实行情，热门层每日刷新涨跌榜，深度层覆盖武器、刀具手套与印花、武器箱等收藏品全库；每款皮肤记录全套磨损档位真实挂牌价，区分普通、StatTrak™ 与纪念版，并积累每日价格快照与历史走势。原生 HTML/CSS/JS 前端搭配 pywebview 桌面壳，支持中文别名搜索、收藏夹，以及按 2025-10 规则自动枚举最优配方的炼金模拟器，最终打包成单个 exe，开箱即用。
